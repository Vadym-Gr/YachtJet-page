# YachtJet-page

Адаптивний односторінковий сайт оренди яхт на семантичному HTML, CSS і
JavaScript. Збірка — Vite. Реалізація виконується поетапно за
[макетом Figma](https://www.figma.com/design/GJJbb74KfTkEzwB6Whjd22/YachtJet--Copy-?node-id=0-1).

## Локальний запуск

Потрібен Node.js 24, як у GitHub Actions.

```sh
npm ci
npm run dev
```

Адресу локального сервера Vite показує в терміналі.

```sh
npm run build
npm run preview
npm run format
npm run format:check
```

## Структура

- `src/index.html` — головна сторінка, яка підключає секції через `<load>`.
- `src/partials/` — header, hero, about, yachts, advantages, rent, reviews,
  footer.
- `src/css/index.css` — точка входу для стилів і нормалізатора.
- `src/css/tokens.css` — кольори та шрифт; `base.css`, `reset.css`,
  `container.css`, `utilities.css` — спільні стилі.
- `src/img/icons/` — оригінальні SVG-іконки з макета, включно з hover-станами.
- `src/public/favicon.svg` — фавікон YachtJet з рівномірним фоном і літерами з
  Figma.
- `src/js/` — модулі інтерактивності, зокрема мобільне меню.
- `src/main.js` — точка входу для JavaScript.

Inter 300/400/500 підключено локально з `@fontsource/inter`. Нормалізація —
`modern-normalize`. Контейнер гумовий від 320 px, обмежений 375 px для mobile;
наступні переходи — 768, 1280 і 1440 px.

## Поточний етап

Етапи 1–9 завершено: підготовлено основу, реалізовано Header, Hero, About, Rent,
Footer, Reviews, Advantages, Yachts та мобільне меню. До 768 px навігація
відкривається кнопкою меню; на планшеті й desktop повна навігація залишається в
шапці відповідно до Figma.

Меню закривається кнопкою, Escape, переходом до секції або зміною ширини на
планшетну. Фокус утримується всередині відкритого меню; прокручування фону
блокується. Соціальні посилання поки є заглушками.

Hero містить заголовок, опис та посилання до секції оренди. Шапку розміщено
поверх фону. У `src/img/hero/` збережено вихідне фото Figma у JPEG-варіантах для
звичайних і Retina-екранів; вони перемикаються через `min-resolution`. Фон
масштабується та зміщується плавно між макетними ширинами, затемнення накладено
через CSS. Висота Hero і перекриття About узгоджені спільними змінними, щоб
уникнути стрибків на точках перелому.

About містить світлий текстовий блок і фото флоту, частково перекриваючи Hero.
На desktop текст розташовано у двох колонках, на mobile/tablet — в одній. Фото в
`src/img/about/` має чотири кадрування та варіанти 1×/2×, підключені через
`<picture>` і `srcset`.

Yachts містить три картки з характеристиками та фото 1×/2×. Карусель показує
одну картку на mobile, дві на tablet і три на desktop. Усі картки доступні через
бічні шеврони, свайп або клавіші ←/→, Home/End після фокусування списку. На
межах списку відповідна кнопка неактивна; якщо всі картки видно, неактивні
обидві. Підтримується налаштування зменшення руху. Ціни збережено за Figma;
напис категорії виправлено на `LUXURY YACHTS`. Backend оренди поки не
підключено.

Advantages містить нумерований список чотирьох переваг і фото палуби. Список має
одну колонку на mobile і дві на tablet/desktop; фото розташовано під списком до
1280 px та поруч із ним на desktop. Чотири кадрування фото з варіантами 1×/2×
підключено через `<picture>` і `srcset`.

Rent містить доступну форму оренди й адаптивне фото 1×/2×. Ім’я та email
обов’язкові; телефон і коментар необов’язкові. Якщо телефон заповнено,
перевіряється його формат. Помилки показуються біля полів, фокус переходить до
першого некоректного поля. Після успішної перевірки форма повідомляє, що заявку
не надіслано: backend поки не підключено. Дані не очищуються й не зберігаються у
сховищі браузера. Без JavaScript кнопка недоступна, щоб запобігти випадковому
надсиланню даних у URL.

Reviews містить усі три відгуки з фото клієнтів 1×/2× і використовує спільний
модуль каруселі. На mobile видно одну картку, на tablet — дві, на desktop — три.
Шеврони, свайп і клавіатура працюють незалежно від каруселі яхт; неактивні
кнопки позначені зменшеною непрозорістю. Активні шеврони залишаються білими на
прозорому фоні при наведенні й натисканні.

Footer містить логотип, якірну навігацію, соцмережі та завершальний текст. За
погодженням власника напис виправлено на `Privacy Policy`, рік — 2026. Посилання
на політику конфіденційності й соцмережі поки є заглушками.

Наступний етап — фінальна перевірка всієї сторінки. Локальний план зберігається
в `docs/implementation-plan.md`; папка `docs` ігнорується Git.

## GitHub Pages

Production-збірка створює `dist` зі шляхом `--base=/YachtJet-page/`. Workflow
`.github/workflows/deploy.yml` збирає сайт після push у `main` та публікує його
в `gh-pages`. Підтримується також ручний запуск `Run workflow`.

У `Settings` → `Pages` потрібно вибрати `Deploy from a branch`, гілку
`gh-pages`, папку `/(root)`.

Адреса опублікованого сайту: https://vadym-gr.github.io/YachtJet-page/.

Проєкт походить із шаблона GoIT `vanilla-app-template`.
